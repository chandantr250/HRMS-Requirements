# HRMS Website Comparison, Recommendations & Project Management Module

## HR Dashboard Improvements

**Add to Dashboard** (visible to Manager, Admin, and HR):
- Employee Growth Trend
- Upcoming Birthdays (on the current day, showing everyone with a profile)

**Keep under Reports** (visible to Manager, Admin, and HR):
- Gender Diversity
- New Joiners vs Exits (month-wise)

## Features

### Announcement Board
Show (visible to Manager, Admin, and HR):
- Company News
- Holidays
- Birthdays
- Work Anniversaries

### AI HR Assistant (Chatbot)
Should support natural-language questions such as:
- "Who is absent today?"
- "Generate payroll report."
- "Show employees whose documents are missing."

## Project Management Module

### 1. Project Creation
Manager, Admin, and HR can create projects with:
- Project Name
- Client Name
- Project Manager
- Start Date
- End Date
- Status
- Priority
- Budget

**Example**

| Project | Client | Status |
|---|---|---|
| HRMS Development | Internal | In Progress |
| E-commerce Website | ABC Pvt Ltd | Testing |
| Mobile App | XYZ Ltd | Completed |

### 2. Team Allocation
Assign employees to projects.

| Employee | Project | Role |
|---|---|---|
| Chandan T R | HRMS | Business Analyst |
| Aravind | HRMS | Developer |
| Sirichandana | HRMS | Tester |

### 3. Task Management
Create tasks under each project with: Task Name, Assigned To, Due Date, Priority, Status.

**Statuses:** Pending, In Progress, Testing, Completed, Not yet Started

### 4. Timesheet Tracking
Track hours spent on projects.

| Employee | Project | Hours |
|---|---|---|
| Chandan | HRMS | 8 |
| Aravind | HRMS | 7 |

### 5. Project Dashboard
Show: Total Projects, Active Projects, Completed Projects, Delayed Projects, Team Utilization %, Hours Logged, Project Progress %.

### 6. Project Reports
Generate: Employee-wise project report, Project-wise hours report, Project completion report, Resource allocation report.

## Additional Feature — Client Management
Store: Client Name, Contact Person, Email, Phone Number, Projects Assigned.
